# LaborData
Labor Data for GTAP 12 Database 

This new database is more closely linked to new and improved ILO data. The ILO now provides labor by education and occupation, and labor by occupation by sector (usually for one year) as well as totals and employment (for multiple years). Missing data has been filled and  adjustments made to ensure any constraints are met.   

Please let us know of any issues you might see in the data and suggestions for improvements.
